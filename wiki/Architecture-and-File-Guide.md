# 🏛️ Architecture & File-by-File Guide

[**← Back to Wiki Home**](./Home.md)

This page explains **how TypeFlow's codebase is structured**, **what every file does**, and **why specific architectural decisions were made**.

---

## 1. Why This Architecture? (Design Decisions)

### 1.1 Modular Development + Single-File Deployment (`build.py` $\rightarrow$ `index.html`)
- **The Problem:** Developing a 10,000+ line application inside a single file is unmaintainable, hard to test, and prone to global variable collisions. On the other hand, modern bundler chains (Webpack, Vite, 500 MB of `node_modules`) break offline portability and slow down iteration.
- **The Solution:** Developers edit clean, single-responsibility ES6 files in `src/` and `style.css`. Running `python3 build.py` concatenates the CSS, HTML shell, and ordered JS modules into a single self-contained **`index.html`** (~464 KB) in under 50 milliseconds—requiring **zero external libraries**.

### 1.2 Observable Event-Driven MVC (`EventEmitter`)
- **Strict Separation of Concerns:**
  - **Models (`src/models/`)** hold pure state and math. They **never** touch `document` or DOM elements. Instead, they inherit from `EventEmitter` and emit semantic events (e.g., `flowUpdated`, `eggHatched`, `achievementUnlocked`).
  - **Views (`src/views/`)** subscribe to Model events and update specific DOM subtrees or HTML5 Canvas contexts.
  - **Controllers (`src/controllers/`)** capture raw user input (keystrokes, clicks) and translate them into Model method calls.
- **Why this matters:** Because Models have zero DOM dependencies, the entire game logic suite (`tests/*.js`) runs directly in Node.js in milliseconds without needing a headless browser.

### 1.3 Dual Browser / CommonJS Compatibility
Every file in `src/` ends with a lightweight export guard:
```javascript
if (typeof module !== 'undefined' && module.exports) {
  module.exports = { ... };
}
```
This allows Node.js test files (`tests/*.js`) to `require()` individual modules directly while allowing `build.py` to inline those exact same files into `index.html` for the browser.

## 3. Detailed File Reference (`src/`)

### Core (`src/core/`)
- **[`src/core/EventEmitter.js`](../src/core/EventEmitter.js)**
  - **What it does:** Provides the synchronous publish/subscribe backbone (`on`, `off`, `emit`) inherited by every Model.
  - **Why it's made this way:** Keeps Models completely decoupled from Views so multiple UI components (e.g., `HUDView`, `StageView`, `NestView`) can react to a single state change without spaghetti callbacks.
- **[`src/core/Constants.js`](../src/core/Constants.js)**
  - **What it does:** Centralizes game mode enums (`MODES.FLOW`, `MODES.CLASSIC`), timer durations (`15`, `30`, `60`), flywheel physics constants, and default player save schemas.

### Services (`src/services/`)
- **[`src/services/StorageService.js`](../src/services/StorageService.js)**
  - **What it does:** Wraps `localStorage` under a versioned key (`typeflow_save_v2`), safely merging new schema fields (`flowHistory`, `cosmetics`, `achievements`, `bigramData`) when existing players upgrade.
  - **Why it's made this way:** Prevents corrupt or outdated browser storage from crashing the app when new features ship.
- **[`src/services/AudioService.js`](../src/services/AudioService.js)**
  - **What it does:** Synthesizes all mechanical key switches (*Box Blue, Thoccy Linear, Tactile Brown, Typewriter Bell, Bubble Droplet*), chromatic combo pitch scaling ($2^{n/12}$), error thuds, egg cracks, and trophy fanfares using pure Web Audio API oscillators and noise buffers.
  - **Why it's made this way:** Zero `.mp3` or `.wav` asset files are needed, saving hundreds of kilobytes and eliminating audio network latency.

### Models (`src/models/`)
- **[`src/models/WordsModel.js`](../src/models/WordsModel.js)**
  - **What it does:** Hydrates the 1,000-word dictionary in `<2ms`, classifies each word into 1 of 5 physical motor buckets, computes Classic tier weights, tracks per-word SRS mastery, and builds `[Anchor, New, Anchor]` word sandwiches.
- **[`src/models/BigramLedger.js`](../src/models/BigramLedger.js)**
  - **What it does:** Records inter-key latency and error rates for every character pair ($c_1 \rightarrow c_2$) using an Exponential Moving Average (`alpha = 0.20`), exposing weakest/strongest transitions to `WordsModel`.
- **[`src/models/FlowModel.js`](../src/models/FlowModel.js)**
  - **What it does:** Manages Flow RPG progression: flywheel momentum (`0%–120%`), Apex Cushion stumble damping, `targetWpm` pacing, XP & player leveling, deterministic `eggCharge` (`0%–100%`), and Flow Run qualification/history (`>=85%` start, `>=50%` continuation floor).
- **[`src/models/EggNestModel.js`](../src/models/EggNestModel.js)**
  - **What it does:** Manages the 3-slot Egg Nest array, determines egg rarity tiers (`Common`, `Uncommon`, `Rare`, `Epic`), and processes the 3-keystroke `e-g-g` hatching sequence.
- **[`src/models/SessionModel.js`](../src/models/SessionModel.js)**
  - **What it does:** Tracks the active typing session across both Classic and Flow modes: word queue, current word/char indices, typed character history, cross-word backspace reversion, per-second telemetry snapshots, and WPM/accuracy calculations.
- **[`src/models/AchievementsModel.js`](../src/models/AchievementsModel.js)**
  - **What it does:** Defines all 35 achievements across 5 categories (*Speed, Flow, Hatchery, Hidden, Feats*), evaluates unlock conditions after every word/session, and retroactively syncs historical saves on startup.
- **[`src/models/CosmeticsModel.js`](../src/models/CosmeticsModel.js)**
  - **What it does:** Defines the 32 unlockable items across 6 customization slots (*Themes, Flow FX, Caret Geometries, Caret Modifiers, Ghost Styles, Sound Packs*), checks level/achievement unlock criteria, and manages equipped selections.

### Views (`src/views/`)
- **[`src/views/StageView.js`](../src/views/StageView.js)**
  - **What it does:** Renders the 3-line word stage, smooth subpixel caret positioning, the 60fps `requestAnimationFrame` Ghost Pacer, and the Hidden Horizon (`Char` and `Word Vanish`) opacity masks.
- **[`src/views/HUDView.js`](../src/views/HUDView.js)**
  - **What it does:** Controls the header bar, mode/duration selectors, live WPM/Accuracy/Momentum readouts, synchronized Pace/Ghost/Hidden sliders, achievement micro-toasts, and the contextual Flow Recap pill (`[;;]`).
- **[`src/views/NestView.js`](../src/views/NestView.js)**
  - **What it does:** Renders the 3-slot Egg Nest, the under-stage incubation charge bar, crack animations, and non-intrusive inline onboarding prompts (`tab: hatch`, `type 'egg'`).
- **[`src/views/ChartView.js`](../src/views/ChartView.js)**
  - **What it does:** Renders the multi-curve HTML5 Canvas performance chart (Cumulative WPM, Instantaneous WPM, Raw WPM, `% Flow`, and Fixed/Unfixed Error markers) with interactive hover tooltips for both Classic results and Flow State Recaps.
- **[`src/views/ModalView.js`](../src/views/ModalView.js)**
  - **What it does:** Renders the tabbed modal drawer containing Lifetime Stats, Classic & Flow History tables (with clickable rows to re-inspect past run graphs), the filterable Trophy Case, and the live-preview Cosmetic Armory.

### Controllers & Build (`src/controllers/`, `src/bootstrap.js`, `build.py`)
- **[`src/controllers/KeyboardController.js`](../src/controllers/KeyboardController.js)**
  - **What it does:** Intercepts global keyboard events, isolates input when typing inside number inputs/modals, detects the home-row `;;` double-tap shortcut (within 400ms, suppressing single `;` typos), routes <kbd>Tab</kbd> between Stage and Egg Nest, and handles printable characters, <kbd>Space</kbd>, and <kbd>Backspace</kbd>.
- **[`src/controllers/GameController.js`](../src/controllers/GameController.js)**
  - **What it does:** The central orchestrator that coordinates `SessionModel`, `FlowModel`, `WordsModel`, `EggNestModel`, `AchievementsModel`, and `CosmeticsModel`, manages the 7-second AFK Flow Recap crossfade timer, and triggers saves via `StorageService`.
- **[`src/bootstrap.js`](../src/bootstrap.js)**
  - **What it does:** Instantiates all Services, Models, Views, and Controllers on `DOMContentLoaded` and exposes `window.app` for debugging.
- **[`build.py`](../build.py)**
  - **What it does:** Reads `style.css` and all ordered `src/*.js` files, strips development-only module guards where appropriate, and writes the standalone production `index.html`.
